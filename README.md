Conventions
All agents authenticate through Application Default Credentials (ADC); no API keys appear in any notebook.
Each notebook is meant to be run top to bottom in Colab Enterprise on a Vertex AI-enabled project - later cells depend on earlier ones.
Environment-driven deviations from the literal lab instructions (e.g. geocoding provider, model choices) are documented in each day's notebooks.
